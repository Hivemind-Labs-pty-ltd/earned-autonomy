# Security

Please don't report security problems in public issues.

Email **[hello@hivemind.au](mailto:hello@hivemind.au)** with "Security" in the subject. Tell us what you found, where,
and how to reproduce it. We'll reply within five working days and keep you updated until it's fixed.

This covers the reference engine and conformance tests. For problems with the methodology itself, such as a rule that
could let an agent gain trust it hasn't earned, email us too: we treat those as security issues.
